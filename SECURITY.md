# Security Policy

## Official Distribution

Official MeshBBS releases are distributed only through:

https://github.com/JASON085/MeshBBS/releases

Users should verify that APK files originate from the official MeshBBS
GitHub repository.

## Modified APKs

Modified, repackaged, or redistributed APK files are not official MeshBBS
releases and are not supported.

## Security Reports

If you discover a security issue, please do not disclose sensitive
technical details publicly until the issue has been reviewed.
